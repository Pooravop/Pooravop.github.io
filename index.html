ShopSphere: fault-tolerant e-commerce

A full stack store with a React and Vite storefront, an Express REST API and MongoDB, including JWT authentication, cart, checkout and admin product management. Built as a two-person major project.

View ShopSphere code
  • React
  • Node.js
  • Express
  • MongoDB
  • Redis
  • RabbitMQ
  • Docker

Exactly one order per checkout

Idempotency-Keys and Redis locks make duplicate, timed-out or retried requests resolve to a single order.

Events survive broker outages

A transactional outbox stores the order, payment record and ORDER_CREATED event in one MongoDB transaction, so nothing is lost while RabbitMQ is down.

One reliable processor for every consumer

Payment, inventory, order saga and email consumers share event idempotency, timeouts, retries after 1s, 2s and 4s, and dead-letter queues with replay.

Saga with automatic rollback

A choreography-based saga coordinates payment and inventory, reserves stock, confirms the order and rolls back when a step fails.

Failures you can trigger on purpose

A fault injection module simulates failures, delays, duplicate deliveries and broker outages, fed by a synthetic event generator.

Proof you can inspect

A live Reliability Dashboard shows the guarantees at work, and the project has 58 automated tests.
